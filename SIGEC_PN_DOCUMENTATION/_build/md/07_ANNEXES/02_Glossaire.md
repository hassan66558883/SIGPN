# Glossaire professionnel

**Termes de police, de procédure et du système**

| Rubrique | Valeur |
|---|---|
| Système | SIGEC-PN / SIGPN-T — Système d'information de gestion de la Police nationale du Tchad |
| Éditeur et développeur | TECHNOTCHAD |
| Version du document | 1.0 — 10 novembre 2026 |
| Statut | Projet pour validation par la hiérarchie : les points marqués « À confirmer » ne sont pas des décisions |
| Source des informations | Lecture seule du système existant (code, catalogue des rôles et droits, écrans) — aucune donnée, aucun compte, aucun rôle, aucune permission n'a été modifié |

| Terme | Définition |
|---|---|
| Acquitter | Confirmer qu'une alerte a été prise en compte par l'unité ; l'acte est horodaté. |
| Affaire | Dossier d'enquête ouvert, souvent à partir d'une plainte. |
| Affectation | Désignation d'une personne pour traiter un dossier. |
| Alerte nationale | Diffusion d'un avis de recherche aux unités concernées, avec accusé de réception et escalade. |
| Amende forfaitaire | Amende au montant fixé par le catalogue pour une infraction routière. |
| Approbation (demande d') | Circuit de décision à une ou deux personnes pour les changements sensibles de comptes et de droits. |
| Arrestation | Appréhension d'une personne, enregistrée avec son fondement légal. |
| Audit (journal d') | Registre inaltérable des actions effectuées dans le système. |
| Avis de recherche | Diffusion d'une personne recherchée aux unités ; distinct du mandat. |
| Brouillon | Saisie enregistrée mais non soumise. |
| Chaîne de conservation | Historique des mains par lesquelles passe une pièce à conviction. |
| Clôture | Fin du traitement avec une issue ; le dossier devient en lecture seule. |
| Commissaire | Chef de commissariat ; dans le système, titulaire du profil de commandement de commissariat. |
| Commissariat | Unité de police de base ; peut avoir des postes rattachés. |
| Compte | Accès personnel d'un agent, lié à un rôle et à une unité. |
| Contrôle biométrique | Vérification d'identité par empreinte ou visage ; simulation tant qu'aucun matériel réel n'est connecté. |
| Droit (permission) | Autorisation précise d'effectuer une action ; attribuée à un rôle. |
| Décret 0572/2023 | Décret du 11 avril 2023 portant organisation et fonctionnement du ministère de la Sécurité publique et de l'Immigration. |
| Délégation provinciale | Direction de la police d'une province ; son chef est le délégué provincial. |
| Délégué provincial | Responsable de la police d'une province ; supervise les commissariats. |
| Dépôt public | Plainte ou signalement envoyé par un citoyen via le portail, avant conversion par un agent. |
| Escalade | Remontée d'une alerte non prise en compte au niveau hiérarchique supérieur. |
| Garde à vue | Privation de liberté d'une personne arrêtée, avec échéance légale surveillée. |
| Habilitation | Niveau (Standard, Sensible, Confidentiel) qui conditionne l'usage des droits sensibles. |
| Habilitation de sécurité | Voir Habilitation. |
| Incident | Évènement signalé (trouble, accident, vol…) enregistré avec lieu et gravité. |
| Journal de surveillance | Entrées datées sur l'état d'une personne en garde à vue. |
| Main courante | Registre chronologique des évènements d'un poste ; non construit comme module distinct. |
| Mandat | Acte de l'autorité judiciaire (arrestation, perquisition, détention, citation, saisie) enregistré dans le système. |
| MFA / second facteur | Code à usage unique de l'application d'authentification, en plus du mot de passe. |
| Mise en cause (personne) | Personne visée par une plainte ; rôle « suspect » dans l'affaire. |
| Mutation | Changement d'affectation d'un agent, validé par les RH puis par l'autorité. |
| Notification | Message interne signalant une tâche ou un évènement. |
| OPJ | Officier de police judiciaire ; dans le système, un profil d'officier sans pouvoir judiciaire modélisé. |
| Parquet | Autorité judiciaire de poursuite ; hors système, un profil de consultation existe. |
| Personne recherchée | Personne faisant l'objet d'un avis de recherche. |
| Pièce à conviction | Objet saisi ou recueilli, enregistré avec scellé et lieu de stockage. |
| Plaignant | Personne qui dépose une plainte. |
| Plainte | Déclaration de faits par un plaignant, enregistrée au commissariat. |
| Portail public | Site accessible au citoyen sans compte. |
| PV (procès-verbal) routier | Contravention électronique numérotée émise lors d'un contrôle routier. |
| Périmètre | Étendue territoriale des données visibles : national, province, commissariat. |
| Quatre yeux | Règle selon laquelle celui qui demande ou émet ne peut pas valider. |
| Rapprochement | Comparaison des versements aux recettes encaissées. |
| Rôle | Ensemble de droits attribué à un compte. |
| Scellé | Fermeture numérotée d'une pièce à conviction. |
| Sensible (droit, affaire) | Droit à usage restreint ou affaire à visibilité limitée à son équipe. |
| Session | Période de connexion d'un utilisateur. |
| Statut | État d'un dossier dans son circuit. |
| Superviseur | Personne qui contrôle le travail d'une autre. |
| Transmission | Passage d'une affaire en statut « Transmise » avec l'issue choisie ; l'envoi physique se fait hors système. |
| Unité | Élément de l'organisation : direction, délégation, commissariat, poste, brigade. |
| Versement | Remise à l'administration de l'argent encaissé par un agent. |
| Écart (de caisse) | Différence entre le montant attendu et le montant versé ou déclaré. |
